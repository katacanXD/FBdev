# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина или каталога товаров, разработанную с использованием Bootstrap.

## Используемый фреймворк

Bootstrap.

## Способ подключения

Bootstrap подключён через CDN. Локальная копия фреймворка в `vendor/bootstrap/` не используется.

Используются:

- `https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css` — CSS фреймворка;
- `https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js` — JS Bundle фреймворка;
- `css/custom.css` — собственные стили проекта, подключаются после Bootstrap.
