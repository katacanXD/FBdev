# НИИ ИТ — главная страница

Учебный проект контрольной работы №2 по теме «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Практика 9

Собрана главная страница сайта научно-исследовательского института информационных технологий.

Реализовано:

- подключение Bootstrap 5.3.8 через CDN;
- собственный файл `css/custom.css`;
- шапка с логотипом и Bootstrap-навигацией;
- hero-блок на сетке;
- блок принципов работы;
- сетка последних публикаций;
- подвал страницы.

## Сетка

Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*` и utility-классы отступов.

## Запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8000
```
