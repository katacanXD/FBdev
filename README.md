# НИИ ИТ — сайт исследовательского института

Учебный проект контрольной работы №2 по теме «CSS-фреймворки: разработка интерфейса на Bootstrap».

Сайт научно-исследовательского института информационных технологий: публикации, направления, требования к авторам, информация об институте и контакты. Все публикации, авторы и реквизиты — демонстрационные заглушки.

## Ветки

- `kr2-base` — минимальная версия для практических занятий №9–10: четыре страницы, Bootstrap через CDN.
- `kr2-final` — итоговая версия для сдачи КР №2: локальный Bootstrap, семь страниц, фильтры, дополнительные компоненты и общий дизайн.

## Стек

- HTML5;
- Bootstrap 5.3.8;
- CSS (`css/custom.css`);
- JavaScript (`js/main.js`);
- Git.

## Подключение Bootstrap

Bootstrap подключён локально, без CDN:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

`css/custom.css` подключён после Bootstrap, поэтому может переопределять его стили. Локальное подключение выбрано как самостоятельная доработка: сайт работает без интернета, а версия фреймворка зафиксирована в проекте.

## Страницы

| Файл | Роль | Что на странице |
|---|---|---|
| `index.html` | Главная | hero-блок, принципы, направления, последние публикации, карусель событий, призыв подать статью |
| `catalog.html` | Каталог публикаций | поиск, фильтр по направлению, сортировка, пять демонстрационных карточек, аккордеон вопросов, модальное окно подписки |
| `product.html` | Страница публикации | аннотация и метаданные во вкладках, боковая колонка, демонстрационная пометка |
| `order.html` | Подача статьи | форма автора и статьи, загрузка файла, валидация, модальное подтверждение |
| `requirements.html` | Требования | четыре этапа, аккордеон требований, переход к форме подачи |
| `about.html` | Об институте | миссия, история, направления, команда, партнёры, события |
| `contacts.html` | Контакты | адрес, реквизиты, форма вопроса, условная схема проезда |

Файлы `catalog.html`, `product.html` и `order.html` сохранены с именами из методических указаний. По смыслу это каталог публикаций, страница публикации и форма подачи статьи.

## Сетка

Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `col-xl-*`, `g-*`, `gx-*`, `gy-*` и utility-классы отступов. `container-fluid` применяется для широкого hero-блока, `container` — для основного содержимого.

## JavaScript

Один файл `js/main.js` с двумя задачами:

1. Фильтрация публикаций в каталоге: поиск по названию, автору и теме, фильтр по направлению, сортировка по дате или названию, счётчик результатов и пустое состояние.
2. Валидация формы подачи статьи через Bootstrap: проверка обязательных полей и модальное окно подтверждения.

JS не обязателен для просмотра сайта: без него видны все пять публикаций, а форма проверяется браузером. Бэкенда нет: данные не отправляются, файлы не загружаются.

## Демо-контент

- Пять публикаций, все с пометкой «Демо».
- Только первая карточка ведёт на `product.html`; остальные не кликабельны.
- Полных текстов, PDF и DOI нет.
- Формы демонстрационные: показывают состав полей и валидацию, но ничего не отправляют.

## Запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8000
```

После запуска открыть `http://localhost:8000`.

## Проверка

- страницы открываются на ширинах 375, 768, 1024 и 1440 px;
- навигация сворачивается на планшете и телефоне;
- карточки перестраиваются в 1, 2 и 3 колонки;
- фильтры, сортировка и поиск работают;
- модальные окна открываются и закрываются;
- форма не отправляется с пустыми обязательными полями;
- в консоли нет ошибок, все локальные ссылки ведут на существующие файлы.

## GitHub Pages

Опубликовать ветку `kr2-final`:

1. Открыть настройки репозитория `Settings → Pages`.
2. Выбрать `Deploy from a branch`.
3. Указать ветку `kr2-final` и папку `/ (root)`.
4. Сохранить и открыть выданную ссылку.
