# НИИ ИТ — сайт исследовательского института

Учебный проект контрольной работы №2 по теме «CSS-фреймворки: разработка интерфейса на Bootstrap».

Сайт научно-исследовательского института информационных технологий: публикации, направления, требования к авторам, информация об институте и контакты. Публикации, авторы и реквизиты — вымышленные.

## Ветки

- `kr2-base` — минимальная версия для практических занятий №9–10: четыре страницы, Bootstrap через CDN.
- `kr2-final` — итоговая версия для сдачи КР №2: локальный Bootstrap, статьи в отдельной папке, фильтры, карта и общий дизайн.

## Стек

- HTML5;
- Bootstrap 5.3.8;
- CSS (`css/custom.css`);
- JavaScript (`js/main.js`, `js/map.js`);
- Git.

## Подключение Bootstrap

Bootstrap подключён локально, без CDN:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

`css/custom.css` подключён после Bootstrap, поэтому может переопределять его стили. Локальное подключение выбрано как самостоятельная доработка: сайт работает без интернета, а версия фреймворка зафиксирована в проекте.

## Сетка

Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `col-xl-*`, `g-*`, `gx-*`, `gy-*` и utility-классы отступов. `container-fluid` применяется для широкого hero-блока, `container` — для основного содержимого.

## JavaScript

`js/main.js`:

1. Фильтрация публикаций: поиск по названию, автору и теме, фильтр по направлению, сортировка по дате или названию, счётчик результатов и пустое состояние.
2. Валидация формы подачи статьи через Bootstrap: проверка обязательных полей и модальное окно подтверждения.
3. Скрытие ещё не загруженных изображений, чтобы вёрстка не ломалась до добавления файлов.

`js/map.js`:

- подключает Yandex Maps JS API 2.1;
- берёт ключ из `js/map-config.js` (файл в `.gitignore`);
- строит интерактивную карту с центром на `55.670155, 37.481102`;
- ставит метку с подсказкой и балуном на проспект Вернадского, 78;
- если ключа нет или API не загрузился, показывает статическую карту со ссылкой на Яндекс Карты.

Бэкенда нет: данные форм не отправляются на сервер, файлы не загружаются. Подтверждение формы показывает модальное окно.

## Карта

Страница `contacts.html` содержит контейнер `#map`, а `js/map.js` подставляет в него интерактивную карту.

Ключ хранится в `.env`:

```text
MAP_API_KEY=...
```

Локально из `.env` создаётся `js/map-config.js`:

```bash
python -c "import re,pathlib; t=pathlib.Path('.env').read_text(); k=re.search(r'^MAP_API_KEY=(.+)$', t, re.M).group(1).strip(); pathlib.Path('js/map-config.js').write_text('window.MAP_API_KEY = %r;\n' % k)"
```

`js/map-config.js` добавлен в `.gitignore` и не попадает в репозиторий. На GitHub Pages ключ подставляет workflow из секрета `MAP_API_KEY`.

Координаты: `55.670155, 37.481102` (широта, долгота). В API 2.1 центр задаётся в порядке `[широта, долгота]`, в статической карте — `долгота,широта`.

## Запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8000
```

После запуска открыть `http://localhost:8000`.

## GitHub Pages

Проект публикуется через GitHub Actions, чтобы не коммитить ключ карты.

1. Открыть `Settings → Pages`.
2. В `Build and deployment → Source` выбрать `GitHub Actions`.
3. Открыть `Settings → Secrets and variables → Actions`.
4. Создать секрет `MAP_API_KEY` со значением ключа Yandex Maps API.
5. Сделать push в ветку `kr2-final` — workflow `.github/workflows/pages.yml` соберёт сайт и подставит ключ в `js/map-config.js`.

Если выбрать `Deploy from a branch`, сайт тоже откроется, но без секрета: карта будет статической, без интерактива.
