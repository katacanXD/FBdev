# НИИ ИТ — сайт исследовательского института

Учебный проект контрольной работы №2 по теме «CSS-фреймворки: разработка интерфейса на Bootstrap».

## О проекте

Сайт научно-исследовательского института информационных технологий: публикации, направления исследований и подача статьи. Вся предметная область — демонстрационная: публикации, авторы и реквизиты являются заглушками.

Ветка `kr2-base` содержит минимальную версию для практических занятий №9–10.

## Стек

- HTML5;
- Bootstrap 5.3.8 (CDN);
- CSS (`css/custom.css`);
- Git.

## Страницы

- `index.html` — главная: hero-блок, принципы, последние публикации, призыв подать статью;
- `catalog.html` — каталог из пяти демонстрационных публикаций, модальное окно подписки, аккордеон вопросов;
- `product.html` — демонстрационная страница публикации;
- `order.html` — демонстрационная форма подачи статьи.

## Bootstrap-компоненты

`navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `accordion`, `breadcrumb`, `form-control`, `form-select`, `input-group`, `form-check`, `list-group`, `table`.

## Сетка

Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*` и utility-классы отступов.

## Запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8000
```

После запуска открыть `http://localhost:8000`.

## Демо-контент

Публикации, авторы, контакты и реквизиты вымышлены. Ссылка «Пример страницы» ведёт только на одну демонстрационную страницу публикации; остальные карточки не кликабельны.
