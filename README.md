# 33 ОБОРОТА — виниловая лавка

Собственная реализация интернет-магазина на основе проекта КР №2 (ветка `kr2`):
та же предметная область — каталог и заявка, — но своя идея, свой визуальный язык
и живое поведение вместо статичных заглушек.

**Ветка:** `feature/vinyl-shop-33oborota`
**Основа:** `kr2` (Bootstrap Shop, КР №2)

## Идея

Не «ещё один учебный магазин», а лавка винила на Покровке. У неё есть характер:
честное описание состояния пластинок, проверка иглой, б/у-полка, разговоры про музыку.
Отсюда и всё остальное — палитра бумажных конвертов, крупная типографика, полки-разделители
и проигрыватель, который можно включить прямо на главной.

Название «33 ОБОРОТА» — от скорости вращения пластинки: 33⅓ об/мин.

## Что живёт на сайте

Всё состояние — в `localStorage`, поэтому корзина и избранное переживают перезагрузку.

- **Корзина** — оффканвас-панель из любой страницы, счётчик в шапке, изменение количества,
  прогресс до бесплатной доставки, отдельная страница корзины.
- **Промокод** — `VINYL10` (−10%) и `PLATINKA15` (−15%), скидка пересчитывается в корзине и в заказе.
- **Избранное** — сердечко на карточке, счётчик в шапке, фильтр «только избранное» в каталоге.
- **Каталог** — поиск, жанры, десятилетия, цена, состояние, сортировка, чипы активных фильтров,
  подгрузка по кнопке, пустое состояние. Состояние фильтров синхронизировано с адресной строкой
  (ссылкой можно поделиться).
- **Быстрый просмотр** — модальное окно с обложкой и кнопкой в корзину.
- **Страница пластинки** — собирается по `?id=`, вкладки «Описание / Характеристики / Доставка»,
  похожие пластинки и «вы недавно смотрели».
- **Оформление** — пересчёт доставки (курьер / ПВЗ / самовывоз, бесплатно от 5 000 ₽),
  валидация формы, номер заказа и подтверждение.
- **Главная** — проигрыватель, который ставит пластинку по клику, полка новинок, жанровые плитки,
  четыре шага проверки, отзывы, FAQ, подписка.
- **Тосты** — короткие подтверждения действий; анимация уважает `prefers-reduced-motion`.

## Дизайн

| Что | Решение |
|---|---|
| Палитра | бумага `#f1ede2`, хвойный `#13322a`, кислотный `#e9ff5c`, оранжевый `#ff6b35` |
| Типографика | Unbounded (заголовки), Manrope (текст) — обе с кириллицей |
| Приёмы | бумажное зерно, жёсткие тени-смещения, наклонные стикеры, полки-разделители |
| Сетка | Bootstrap 12 колонок, `container` / `row` / `col-*`, `g-*` |

Bootstrap остаётся базой: сетка, `navbar`, `card`, `btn`, `badge`, `alert`, `modal`,
`offcanvas`, `accordion`, `tabs`, `carousel`, формы и утилиты. Собственный CSS — это
дизайн-система поверх фреймворка, а не замена ему.

## Запуск

Сайт статический, сборка не нужна.

- Открыть `index.html` двойным щелчком — работает (скрипты обычные, не модули).
- Или поднять локальный сервер, чтобы адреса выглядели как на хостинге:

```bash
python -m http.server 8000
# http://127.0.0.1:8000
```

## Изображения

Пока картинок нет, обложки рисуются из палитры пластинки и типографики, а фотополоса —
из бумажной фактуры. Файл с нужным именем подставляется автоматически, ничего в коде
менять не нужно.

Полный список — в [`images/README.md`](images/README.md). Коротко:

- 18 обложек `images/covers/<id>.jpg`, квадрат 1000 × 1000;
- 3 фотографии лавки `images/shop/{crate,needle,shelf}.jpg`;
- соцпревью `images/og-cover.jpg`, 1200 × 630.

## Отличия от `kr2`

| Было в `kr2` | Стало |
|---|---|
| 4 страницы с «Товар 1–3» | 5 страниц, 18 пластинок с описаниями и характеристиками |
| Статичные карточки | Карточки собираются из данных, корзина и избранное живут в браузере |
| Форма-заявка без логики | Оформление с пересчётом доставки, промокодом и валидацией |
| Нет фильтров | Поиск, жанр, десятилетие, цена, состояние, сортировка, ссылки с параметрами |
| Один `accordion` как доп. компонент | `offcanvas`, `modal`, `tabs`, `carousel`, `toast` + свой JS |

Цены, наличие и состояние — демонстрационные: это учебный проект, оплата не списывается.
