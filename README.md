# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — страница каталога товаров с фильтрами;
- `product.html` — страница отдельного товара с таблицей характеристик;
- `order.html` — страница оформления заявки на заказ;
- `contacts.html` — страница контактов и формы обратной связи;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт модального окна и валидации форм;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

В проекте используются:

## Использование Flexbox и CSS Grid

- **Flexbox применён для:**
    - выравнивания и компоновки шапки сайта (`site-header__inner`);
    - горизонтального меню навигации (`site-nav__list`);
    - подвала сайта (`site-footer__inner`);
    - внутренней структуры карточек товаров (выравнивание цен и кнопок по нижнему краю);
    - хлебных крошек и групп кнопок в формах (`form-actions`).
- **CSS Grid применён для:**
    - сложной двухколоночной структуры каталога (`catalog-layout`: панель фильтров 240px + контент);
    - адаптивной сетки товаров (`products-grid`) с функцией `repeat(auto-fill, minmax(260px, 1fr))`;
    - сетки блока преимуществ (`advantages__list`) на главной странице;
    - детальной страницы товара (`product-detail`: медиа-блок + параметры).

## Базовое позиционирование элементов

В проекте продемонстрированы ключевые типы позиционирования:
- `position: relative` — задан контейнерам карточек (`.product-card`) для создания контекста позиционирования;
- `position: absolute` — использован для размещения информационных бейджей («Хит», «Новинка», «Скидка») в углах карточек;
- `position: sticky` — закрепляет боковой блок фильтров (`.catalog-filters`) при прокрутке каталога;
- `position: fixed` — фиксирует плавающую кнопку перехода к началу страницы (`.scroll-top`) в правом нижнем углу экрана;
- `z-index` — управляет слоями наложения для модального окна диалога и фиксированной кнопки.

## Именование классов по методологии БЭМ

Классы компонентов сформированы по стандарту Блок-Элемент-Модификатор:
- Блоки: `.site-header`, `.site-nav`, `.product-card`, `.catalog-filters`, `.specs-table`;
- Элементы: `.site-header__logo`, `.site-nav__link`, `.product-card__title`, `.product-card__price`, `.product-card__badge`;
- Модификаторы: `.site-nav__link--active`, `.product-card--discount`, `.product-card__badge--hit`, `.product-card__badge--sale`, `.button--secondary`.

## Описание самостоятельных доработок

1. **Навигационные цепочки (Хлебные крошки):** добавлен блок `.breadcrumbs` на всех страницах второго уровня для быстрого возврата на главную.
2. **Плавающая кнопка «Наверх»:** реализована кнопка со свойством `scroll-behavior: smooth` для плавного скролла страницы.
3. **Разнотипные бейджи на карточках через модификаторы БЭМ:** создана система акцентных меток (`--hit`, `--new`, `--sale`) с индивидуальным цветовым кодированием.
4. **Стилизованная таблица характеристик:** таблица оформлена с семантическими заголовками `th[scope]`, `caption` и полосатым оформлением четных строк (`:nth-child(even)`).
5. **Sticky-фильтрация:** реализован статический блок фильтров каталога, остающийся в поле зрения при прокрутке списка товаров.
6. **Улучшенная доступность (A11y):** контрастный фокус `:focus-visible` с отступом `outline-offset`, семантические подписи и валидация через `aria-invalid`.
